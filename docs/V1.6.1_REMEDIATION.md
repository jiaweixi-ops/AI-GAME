# V1.6.1 V0 remediation

This remediation addresses the findings in the V1.6 V0 compliance audit.

Fixed before real-save V0 acceptance:

1. `research_verified` no longer treats technology selected as enough; starved selection returns `UNVERIFIED`.
2. blocked work automatically enters the AI replan path; `max_replans` is active and exhaustion safe-stops.
3. Atomic and Task action budgets are independent, task-scoped, restart-persistent only for the same `task_id`.
4. `ControllerLoop` supplies a persistent driver without turning the LLM into a tick loop.
5. `create_task` requires non-empty `success_when`; vacuous completion is blocked.
6. desired-state reconciliation is based on live state, not cursor alone.
7. Watchdog histories reset at task boundaries and detect shorter loops.
8. AI/provider failures create incidents and safe-stop instead of escaping.
9. entity coordinate matching uses tolerance.
10. `get_digest`, `query_technology`, `set_recipe_verified`, and `research_verified` now have coverage.
11. `actions.jsonl` is real newline-delimited JSON.
12. unknown `abort_if` paths fail safe.
13. ACK status is normalized case-insensitively.
14. basic runtime metrics record AI calls, replans, incidents, and safe stops.

Deliberately not added: Blueprint IR, smelting templates, batch construction macros, task preemption, Combat Runtime, rail, run_python, random-new-game autonomy, rocket automation.
